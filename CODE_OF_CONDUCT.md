# Code of Conduct

We want this project to be a respectful place to contribute, ask questions, and learn.

Be considerate, give constructive feedback, assume good intent, and discuss ideas with evidence. Respect privacy and different experience levels. Harassment, personal attacks, discriminatory language, sexualized behavior, threats, and publishing another person's private information are unacceptable.

These expectations apply in issues, pull requests, discussions, and other project spaces. Report concerns to the repository owner through an existing private channel. Do not post sensitive details in a public issue. A dedicated reporting address has not been established.

Maintainers may remove inappropriate content, request changes in behavior, restrict participation, or block contributors. Reports should be treated confidentially to the extent practical; maintainers involved in a concern should not handle its resolution alone when another maintainer is available.
