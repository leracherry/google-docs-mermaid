# Mermaid for Google Docs 0.1.0

Local Mermaid rendering with Workspace-inspired controls, light/dark themes and source-preserving previews.

## Included

- Preview, Split and Code views, zoom, expanded viewing, and source/SVG copying.
- Global preferences and per-document rendering controls.
- Consistent dropdown arrows with comfortable spacing from text and borders.
- Unique SVG references, stale-render protection, syntax-error recovery and viewport-aware rendering.
- Input size limits, SVG sanitization and early rejection of external-resource syntax.
- Updated dependencies, MIT license, documentation and high-resolution screenshots.

## Install

Download `google-docs-mermaid-0.1.0-chrome.zip` below and extract it. Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the extracted folder containing `manifest.json`.

## Supported surface

Version 0.1.0 supports DOM-backed code blocks on Docs document pages. Native Google Docs canvas blocks are outside this release’s scope; native integration is tracked in the project roadmap. Distribution is through the GitHub ZIP, with Chrome Web Store publishing tracked separately.

## Checks

The release pipeline runs dependency auditing, documentation checks, TypeScript checks, 46 unit tests and 11 built-extension browser tests, including 1/10/50/100-block lifecycle fixtures. Screenshots use DOM-backed demo documents.
